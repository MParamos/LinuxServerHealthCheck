LinuxServerHealthCheck

Bienvenue dans la documentation officielle de LinuxServerHealthCheck. Ce framework est un système de surveillance préventive de serveurs Linux, conçu avec une architecture modulaire extrême et entièrement isolé via des conteneurs Docker.

Aperçu

Le système collecte des métriques de performance, analyse les vulnérabilités via Lynis, audite les connexions SSH et surveille la santé de vos conteneurs Docker et services Systemd. Tout est formaté dans un élégant e-mail HTML envoyé périodiquement par un démon cron interne.

Confidentialité Absolue et Base de Données Locale

Contrairement aux solutions SaaS ou aux agents tiers, LSHC garantit une Souveraineté des Données à 100%. Aucune télémétrie ou métrique n'est envoyée à des serveurs externes. Toutes les informations historiques sont stockées dans une base de données locale isolée dans un conteneur. Les données naissent, sont traitées et purgées sur votre serveur, garantissant une confidentialité totale.

Explorez le menu latéral pour apprendre à utiliser, configurer et étendre le système.
