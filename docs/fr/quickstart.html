Guide de Démarrage Rapide

  1. Cloner le Dépôt : Téléchargez le code source sur votre machine hôte.
  2. Configurer les Variables : Copiez le fichier d'exemple vers .env et définissez vos identifiants SMTP, e-mails cibles et mots de passe de base de données.
  3. Construire et Démarrer : Exécutez docker compose build --no-cache && docker compose up -d. Le conteneur orchestrateur installera dynamiquement les dépendances pour les modules actifs.
  4. Exécution Manuelle : Pour forcer un rapport immédiat sans attendre cron, exécutez ./RunManualHealthCheck.sh depuis l'hôte.

Appliquer les Changements : Pour des raisons de sécurité strictes (Infrastructure Immuable), ce conteneur ne recharge pas les fichiers à chaud. Si vous modifiez le fichier .env, vous devez appliquer les changements avec docker compose up -d. Si vous activez ou désactivez des modules dans ModulesInReport.conf, vous devez recompiler le code avec docker compose build --no-cache && docker compose up -d.
