Développement de Modules

La création d'un nouveau module est triviale. Créez un dossier dans src/modules/mon_module avec au moins deux fichiers :

  1. module.sh : Script bash qui récupère des métriques et expose une variable HTML (ex. export MON_HTML="<p>Données</p>").
  2. template.html : Modèle qui appelle votre variable (ex. ${MON_HTML}) à l'intérieur d'un <div class="module-container">.

Ajoutez mon_module au fichier ModulesInReport.conf et c'est terminé ! Le framework injectera la structure automatiquement dans le rapport final.
