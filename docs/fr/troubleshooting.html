Dépannage

  • L'envoi d'e-mail échoue : Vérifiez votre fichier .env et assurez-vous que le port SMTP (généralement 587 ou 465) et les identifiants sont corrects. Assurez-vous d'avoir accès aux "Applications moins sécurisées" ou aux mots de passe d'application si vous utilisez Gmail.
  • Module Corrompu : Si vous voyez une alerte HTML rouge dans le rapport indiquant une corruption, vérifiez que le module contient les fichiers obligatoires et que sa syntaxe bash est correcte.
  • Autorisations Docker : Le conteneur doit fonctionner en mode privileged avec un mappage de volume hôte (/ vers /host) pour auditer le système de base.
