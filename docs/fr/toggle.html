Activation des Modules

Ouvrez le fichier ModulesInReport.conf situé à la racine du projet. Chaque ligne représente le nom du dossier d'un module dans src/modules/.

performance
logical_storage
network_security
# docker_health (Commenté = Désactivé)
Important : Toute modification apportée à ModulesInReport.conf (que ce soit l'ajout d'un nouveau module, sa suppression, sa désactivation ou la réactivation d'un module commenté) nécessite obligatoirement de reconstruire le conteneur pour appliquer les changements d'architecture en exécutant : docker compose build --no-cache && docker compose up -d.
