Quick Start Guide

  1. Clone the Repository: Download the source code to your host machine.
  2. Configure Variables: Copy the example env file to .env and define your SMTP credentials, target emails, and database passwords.
  3. Build and Start: Run docker compose build --no-cache && docker compose up -d. The orchestrator container will dynamically install dependencies for active modules.
  4. Manual Execution: To force an immediate report without waiting for cron, run ./RunManualHealthCheck.sh from the host.

Applying Changes: For strict security reasons (Immutable Infrastructure), this container does not hot-reload files. If you modify the .env file, you must apply the changes with docker compose up -d. If you toggle modules in ModulesInReport.conf, you must rebuild the code with docker compose build --no-cache && docker compose up -d.
