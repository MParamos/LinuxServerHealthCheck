Module Development

Creating a new module is trivial. Create a folder in src/modules/my_module with at least two files:

  1. module.sh: Bash script that fetches metrics and exposes an HTML variable (e.g. export MY_HTML="<p>Data</p>").
  2. template.html: Template that calls your variable (e.g. ${MY_HTML}) inside a <div class="module-container">.

Add my_module to the ModulesInReport.conf file and you're done! The framework will inject the structure automatically into the final report.
