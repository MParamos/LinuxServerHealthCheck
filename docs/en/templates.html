Template Modification

The final view of the sent report is generated by joining a base template (master) and multiple module templates (partials). Both template systems use standard HTML injected with variables via the Bash orchestrator script.

Template Structure

1. Main Template (Master)

Located at src/templates/report.html. It is the "skeleton" of the email and includes the HTML headers, CSS styles, and the global container. It defines a macro-variable ${MODULES_HTML}, where all the content generated by each module will be injected.

2. Module Templates (Partials)

Located at src/modules/module_name/template.html. These are "blocks" that represent the information for a particular module. They are always structured under a <div class="module-container"> to ensure uniformity in the final report.

How They Join

When the orchestrator runs:

  1. It reads the template.html of each active module.
  2. It replaces its internal variables (e.g., ${L_TITLE} or ${METRIC_VALUE}) with actual data.
  3. It concatenates all those generated blocks into a large memory variable.
  4. It opens src/templates/report.html, searches for ${MODULES_HTML}, and injects the entire previous concatenation there, producing the final HTML.
