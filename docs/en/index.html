LinuxServerHealthCheck

Welcome to the official documentation for LinuxServerHealthCheck. This framework is a preventative Linux server monitoring system, designed with extreme modular architecture and fully isolated via Docker containers.

Overview

The system collects performance metrics (CPU, RAM, GPU, Disks), analyzes vulnerabilities via Lynis, audits SSH logins, and monitors the health of your Docker containers and Systemd services. Everything is packaged into an elegant HTML email sent periodically by an internal cron daemon.

Absolute Privacy & Local Database

Unlike SaaS solutions or third-party agents, LSHC guarantees 100% Data Sovereignty. No telemetry or metrics are sent to external servers. All historical information is stored in a local database isolated within a container. Data is born, processed, and purged exclusively on your server, ensuring total privacy and regulatory compliance.
