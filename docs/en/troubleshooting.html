Troubleshooting

  • Email Delivery Fails: Check your .env file and ensure the SMTP port (usually 587 or 465) and credentials are correct. Ensure you have "Less secure app" access or App Passwords if using Gmail.
  • Corrupted Module: If you see a red HTML alert in the report indicating corruption, check that the module contains the mandatory files and that its bash syntax is correct.
  • Docker Permissions: The container must run in privileged mode with host volume mapping (/ to /host) to audit the base system.
