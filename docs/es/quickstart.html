Guía Rápida de Uso

  1. Clonar el Repositorio: Descarga el código fuente en tu máquina host.
  2. Configurar Variables: Copia el archivo de ejemplo a .env y define las credenciales SMTP, correos de destino y contraseñas de base de datos.
  3. Construir e Iniciar: Ejecuta docker compose build --no-cache && docker compose up -d. El contenedor orquestador instalará dinámicamente las dependencias de los módulos activos.
  4. Ejecución Manual: Para forzar un informe inmediato sin esperar al cron, ejecuta ./RunManualHealthCheck.sh desde el host.
