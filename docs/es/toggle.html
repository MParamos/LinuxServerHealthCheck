Activación y Desactivación de Módulos

Abre el archivo ModulesInReport.conf situado en la raíz del proyecto. Cada línea representa el nombre de la carpeta de un módulo en src/modules/.

performance
logical_storage
network_security
# docker_health (Comentado = Desactivado)
Importante: Si añades un módulo que requiere nuevos binarios del sistema operativo (definidos en su packages.txt), debes reconstruir el contenedor con docker compose build --no-cache para que se instalen.
