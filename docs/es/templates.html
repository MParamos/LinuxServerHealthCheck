Modificación de Templates

La vista final del reporte enviado se genera uniendo una plantilla base (master) y múltiples plantillas de módulos (partials). Ambos sistemas de plantillas utilizan HTML estándar inyectado con variables mediante el script orquestador Bash.

Estructura de las Plantillas

1. Plantilla Principal (Master)

Se encuentra en src/templates/report.html. Es el "esqueleto" del correo electrónico e incluye las cabeceras HTML, estilos CSS y el contenedor global. Define una macro-variable ${MODULES_HTML}, donde se inyectará todo el contenido generado por cada módulo.

2. Plantillas de Módulo (Partials)

Se encuentran en src/modules/nombre_modulo/template.html. Son "bloques" que representan la información de un módulo en particular. Se estructuran siempre bajo un <div class="module-container"> para asegurar la uniformidad en el informe final.

Cómo se unen

Cuando el orquestador se ejecuta:

  1. Lee el template.html de cada módulo activo.
  2. Reemplaza sus variables internas (ej. ${L_TITLE} o ${METRIC_VALUE}) con datos reales.
  3. Concatena todos esos bloques generados en una gran variable de memoria.
  4. Abre src/templates/report.html, busca ${MODULES_HTML} e inyecta ahí toda la concatenación anterior, produciendo el HTML final.

Nota Legal (Licencia GPLv3)

Puedes cambiar totalmente la cabecera, añadir tus propias imágenes, modificar los estilos CSS, cambiar los nombres y alterar toda la estructura visual para adaptarla a tu empresa. Lo único que tiene que respetarse obligatoriamente, de acuerdo con la sección 7(b) de la licencia GPLv3 (preservación de avisos legales y autoría), es que no está permitido eliminar mi autoría ni el enlace a la licencia original del pie de página (footer) de la plantilla principal (report.html). Puedes mover el footer de sitio si quieres, pero debe ser visible para el receptor del correo.
