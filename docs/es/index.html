LinuxServerHealthCheck

Bienvenido a la documentación oficial de LinuxServerHealthCheck. Este framework es un sistema de monitorización preventiva de servidores Linux, diseñado con una arquitectura modular extrema y aislado completamente mediante contenedores Docker.

Visión General

El sistema recopila métricas de rendimiento (CPU, RAM, GPU, Discos), analiza vulnerabilidades a través de Lynis, audita inicios de sesión SSH y vigila el estado de tus contenedores Docker y servicios de Systemd. Todo ello se agrupa y formatea en un elegante correo electrónico HTML que se envía periódicamente mediante un demonio cron interno.

Privacidad Absoluta y Base de Datos Local

A diferencia de soluciones SaaS o agentes de terceros, LSHC garantiza el 100% de la Soberanía del Dato. No se envía telemetría ni métricas a servidores externos. Toda la información histórica se guarda en una base de datos local aislada dentro de un contenedor. Los datos nacen, se procesan y mueren en tu servidor, asegurando privacidad total y cumplimiento normativo.

Explora el menú lateral para aprender a utilizar, configurar y expandir el sistema.
