Aviso Legal y Privacidad

Este sitio web es puramente informativo, de naturaleza técnica y de código abierto. Al no constituir una actividad comercial, no aplica la obligación de registro mercantil según la normativa española (LSSI-CE).

1. Privacidad y Rastreo

Fieles a la filosofía de privacidad absoluta del proyecto LSHC, este sitio web no utiliza cookies, no emplea píxeles de seguimiento, no almacena direcciones IP en bases de datos externas y utiliza tipografías locales del sistema. Este sitio se ha diseñado bajo el principio de máxima privacidad para el usuario.

2. Contacto y Datos

Cualquier comunicación dirigida al correo de contacto será tratada con estricta confidencialidad. Las direcciones de correo electrónico no se cederán a terceros ni se utilizarán para envíos comerciales (Spam). Solo se usarán para dar respuesta a la consulta planteada.

El código, el diseño y la documentación se distribuyen bajo la licencia GPL 3, asegurando que el software permanezca libre y de código abierto.
