Desarrollo de Nuevos Módulos

Crear un módulo nuevo es trivial. Crea una carpeta en src/modules/mi_modulo con al menos dos archivos:

  1. module.sh: Script bash que obtenga métricas y exponga una variable HTML (ej. export MI_HTML="<p>Datos</p>").
  2. template.html: Plantilla que llame a tu variable (ej. ${MI_HTML}) dentro de un <div class="module-container">.

Añade mi_modulo al archivo ModulesInReport.conf ¡y listo! El framework inyectará la estructura automáticamente en el informe final.
