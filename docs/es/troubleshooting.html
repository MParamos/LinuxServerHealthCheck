Resolución de Problemas

  • Falla el envío de correos: Revisa el archivo .env y asegúrate de que el puerto SMTP (usualmente 587 o 465) y las credenciales son correctos. Asegúrate de tener permisos de "Aplicación menos segura" o contraseñas de aplicación si usas Gmail.
  • Módulo Corrupto: Si ves una alerta HTML roja en el informe indicando corrupción, revisa que el módulo contenga los archivos obligatorios y que su sintaxis bash sea correcta.
  • Permisos Docker: El contenedor debe correr en modo privileged y con mapeo de volúmenes de host (/ a /host) para auditar el sistema base.

¿Tienes alguna duda o no logras resolver el problema? No dudes en contactarme aquí.
